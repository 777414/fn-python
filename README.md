# Python Lab — учебный курс

Веб-презентация курса Python для детей 10–12 лет. Статический сайт на HTML, CSS и JavaScript, рассчитанный на публикацию через GitHub Pages.

## Структура

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── course-data.js
│   ├── navigation.js
│   ├── presentation.js
│   └── app.js
└── README.md
```

## Локальный запуск

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python -m http.server 8000
```

Затем перейдите на http://localhost:8000.

## Управление презентацией

- `←` / `→` — предыдущий / следующий слайд
- `M` — открыть меню курса
- `F` — полноэкранный режим
- `Esc` — закрыть меню / выйти из полноэкранного режима средствами браузера

## Наполнение курса

Все 9 модулей и 36 занятий уже заведены в `js/course-data.js`. Подробные учебные материалы будут создаваться по одному занятию после просмотра и согласования. Общие компоненты и визуальный стиль находятся в `css/style.css` и `js/presentation.js`.

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните настройки.
