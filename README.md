# Python дети (начинающие)

Учебный курс Python для детей 10–12 лет. Здесь ребята знакомятся с программированием постепенно: разбираются в основах языка, решают практические задачи и создают собственные проекты.

Курс построен вокруг понятных объяснений, интерактивных материалов и практики. Новые темы закрепляются небольшими заданиями, а знания постепенно складываются в самостоятельные программы.

## О курсе

- **Для кого:** дети 10–12 лет, начинающие изучать программирование.
- **Формат:** интерактивные занятия и практические проекты.
- **Главная цель:** научить не просто писать код, а понимать, как работают программы, мыслить алгоритмически и самостоятельно находить решения.

## Управление презентацией

- `←` / `→` — предыдущий / следующий слайд
- `M` — открыть меню курса
- `F` — полноэкранный режим
- `Esc` — закрыть меню или выйти из полноэкранного режима средствами браузера
